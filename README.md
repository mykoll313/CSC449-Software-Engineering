# CSC449-Software-Engineering
Background
You are about to start a new software development project and need an environment to manage it. In this instance, you do not need an Enterprise solution, such as Jira or Gitlab. Your team will use GitHub (https://www.github.com ).

In this assignment, you will set up a new Project Board in GitHub. Once that is completed you will also set up a Code Repository in GitHub and link it to the Project that you created.

 

Instructions
You should register and create a free account at https://www.github.com.

Create one GitHub Project Board and Code Repository. Initialize your Code Repository with a ReadMe file. Link your project board to your code repository.

What to Submit: Submit your GitHub Project link to your instructor.

Review the links provided in the additional resources section below on how to do these tasks.

 

Additional Resources
GitHub documentation online on how to set up project boards.
GitHub documentation online on how to set up a new repository.
GitHub documentation online on how to link a repository to a board.
